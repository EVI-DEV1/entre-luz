# Entre Luz

Uma landing page narrativa sobre dor emocional, autocrítica, sobrevivência e reconstrução. O conteúdo foi tratado como expressão pessoal e não como afirmações factuais.

## Tecnologias

- React
- TypeScript
- Vite

## Executar localmente

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```
